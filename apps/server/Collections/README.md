# Nonogram and Hashi collections

| Source | Game | Availability |
| --- | --- | --- |
| [The World at Play](https://theworldatplay.com/en/nonogram#picture-credits) | Nonogram | 32 original CC0 5×5 boards imported from an offline snapshot. |
| [Sen Ltd](https://github.com/sen-ltd/nonogram) | Nonogram | Five MIT-licensed picture boards from 5×5 to 10×10. |
| [Sen Ltd](https://github.com/sen-ltd/hashiwokakero) | Hashi | Six MIT-licensed, generated boards from 4×4 to 10×10, including rectangular puzzles. Kobo and the dashboard show **Generated by Sen Ltd**. |
| [Janko Hashi](https://www.janko.at/Raetsel/Hashi/index.htm) | Hashi | Optional archive refresh. A live scan of the first 40 pages stored 29 verified boards from 5×5 to 15×15. |
| [Janko Nonogramme](https://www.janko.at/Raetsel/Nonogramme/index.htm) | Nonogram | Optional archive refresh using the same per-puzzle license check. The first 40 pages supplied no eligible boards for import. |

The World at Play and Sen Ltd packs are embedded in the server and imported once at startup. Their Nonogram grids include one exact duplicate, leaving 36 distinct boards when both packs are imported. Set `ExtraCollections__BundledEnabled=false` to disable automatic import. This setting defaults to `CatalogRefresh__Enabled` when supplied.

A server may enable the Janko scanner with `ExtraCollections__JankoEnabled=true`. The scanner checks the license link on each puzzle page and imports only the supported Creative Commons grants. For a noncommercial deployment, set `ExtraCollections__AllowNonCommercial=true` to also include puzzles with a BY-NC-SA grant. Each puzzle retains its published author, source page and license. The Nonogram and Hashi scans resume independently in batches of 40 pages. They pause between batches and check the archive again one week after completing a scan. [Janko’s BY-NC-SA terms](https://www.janko.at/Raetsel/Creative-Commons.htm)

Run a manual import with the server stopped or running against the same database.

```sh
dotnet run --project apps/server -- refresh-extra-collections --source world-at-play
dotnet run --project apps/server -- refresh-extra-collections --source sen-ltd
dotnet run --project apps/server -- refresh-extra-collections --source janko --game hashi --allow-non-commercial true
```

The importer derives black-and-white Nonogram clues and proves every cell from line constraints. It stores the board only when the proof agrees with the publisher’s grid. The new Nonogram packs carry a line-logic rating. They have no WebPBN difficulty or quality stars. Hashi uses the same exact uniqueness check and difficulty classifier as Bridges. When the publisher supplies bridge marks, the importer checks them against the verified solution. These checks can exclude puzzles a human could otherwise solve. Reimporting the same layout preserves its existing ID and attribution. Hashi collection stock is shown in the dashboard catalog alongside Bridges. Only the local Bridges generator counts toward its generation targets.

Kobo **Game settings → Catalog and queue filters → Source** selects a collection or generator. Hashi also supports separate width and height filters for rectangular boards.
